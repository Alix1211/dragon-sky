# Dragon Sky - 현재 설계 메모

## 전체 플레이 흐름
비행 슈팅 → 파밍 → 부유 상인 → 보스 예고 → 함선 외부전 → 침투 턴제 → 탈출/다음 구역.

## 비행 전투
- 360° 자유 이동.
- 기본 자동공격은 기수 기준 전방 120°.
- 적도 플레이어 방향으로 기수를 돌리고 자기 전방 사격각 안에서만 발사.
- 잡몹은 무쌍에 가깝게 빠르게 정리.
- 중형기 이상은 보호막/후광/파동/대형탄/레이저 등으로 시각적 등급 차이를 둔다.
- 배경은 원본 이미지를 좌우/상하 반전해 청크 반복 티를 줄이고, 구름/부유물 레이어로 깊이를 만든다.

## 파밍과 상인
- 드랍 장비는 필드에서 세부 옵션을 바로 확인하지 않는다.
- 부유 상인에게서 장비 감정/비교/장착/판매 가능.
- 상인은 그리핀 등 비행 생물을 탄 전장 심부름꾼 성격.
- 상인 등장 이후 보스가 나오는 흐름으로 보스전 준비 페이즈를 만든다.

## 턴제 전투
- 중간급 함선: 내부 진입 후 단일 전투.
- 네임드급 모선: 병사전 몇 회 + 네임드/함장 보스.
- 최종부: 슈팅과 내부 턴제를 섞는 복합전 검토.

### 플레이어 명령
- 용사: 공격 / 스킬 / 도구
- 인간형 드래곤: 공격 / 마법 / 도구
- 공격 하위: 일반공격 / 강공격
- 스킬·마법은 습득 목록을 표시.
- 단일/광역 공격이 생기면 대상 선택이 필요하나 프로토타입은 자동 선택.

### ATB UI 방향
- 평상시 화면에는 적 2~3기가 부유하며 함선 배경의 사이렌/연기/스파크가 계속 움직인다.
- 좌하단 드래곤: 흰색·붉은색 오브/프레임형 행동 게이지.
- 우하단 용사: 검·방패 + 푸른 불꽃 테마 행동 게이지.
- 행동력 MAX 시 해당 버튼을 눌러 캐릭터 턴 진입.
- 캐릭터는 좌우 슬라이드보다 '작고 흐림 → 확대되며 선명 → 행동 → 흐려지며 빠짐' 연출을 우선한다.
- 자기 턴에는 한 캐릭터가 화면을 크게 점유하고 명령 메뉴가 펼쳐진다.
- 적도 자기 공격턴에 화면을 크게 점유하는 전용 스킬 연출을 쓴다.

### 연계기
- 공용 연계 게이지가 가득 찬 것만으로는 발동하지 않는다.
- 연계 게이지 MAX + 용사/드래곤 둘 다 행동력 MAX일 때 두 캐릭터 버튼 동시 입력으로 발동.
- 햅틱 + 화면 흔들림 + 플래시 + 파티클 + 전기 + 불꽃 + 프레임/문양 난사를 섞은 과장된 대형 연출.

## 연출 원칙
- 턴제는 동시 객체 수가 적으므로 이펙트 예산을 넉넉하게 사용한다.
- 기술 자체의 실제 모션은 단순해도 기술명/검기/마법진/파티클/화면효과로 풍성하게 만든다.
- 여성 인간형 드래곤은 '의상 손상 버전'을 만들지 않고 피격은 표정·플래시·흔들림·오버레이 등으로 표현한다.
