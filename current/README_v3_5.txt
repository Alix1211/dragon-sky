Dragon Sky v3.5 SOURCE

이번 수정:
1) 스테이지 선택 화면
- 드래곤+카엘 비행 애니메이션을 배경 바로 위(z-index 1)에 배치
- 이전보다 약 25~30% 크게
- 화면 왼쪽으로 조금 더 빼고 위쪽으로 조정
- 드래곤 레이어는 pointer-events:none
- 레이어 순서: 배경 -> 드래곤 라이더 -> 경로 -> 부유섬 -> UI
- 1-1 진입/오프닝/강제 스테이지 종료 기능 유지

2) 슈팅 인게임 스킬 UI
- 기존 원형 HTML 버튼 디자인 제거
- 새 중세/판타지 UI 에셋 적용
- 왼쪽: 드래곤 장식 + 3보석 (브레스/번개/결계)
- 오른쪽: 검/방패 장식 + 3보석 (강참/회전참/관통참)
- 쿨타임 없음, 기존 공용 SYNC MP 사용
- 마나 충분: 보석 주변 라이트 펄스
- 마나 부족: 보석 위에 어두운 오버레이
- 누를 때 짧은 확대 반응
- blur/backdrop-filter를 스킬 UI에 사용하지 않음
- 스킬 UI 텍스트는 고정. 매 갱신마다 DOM 텍스트를 바꾸지 않음

빌드/컴파일 없음. HTML/CSS/JS 원본 소스 수정.
