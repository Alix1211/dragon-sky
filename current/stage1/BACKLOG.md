# Dragon Sky 누적 백로그

## 현재 구현/검증
- 360도 공중 슈팅, 전방 120도 자동공격
- 무쌍형 잡몹 구간
- 중급기 격파 -> 내부 턴전투 -> 대폭발/침몰 -> 필드 복귀
- 부유 상인/그리핀 상점
- 상점 종료 30초 뒤 네임드
- 미감정 장비 드랍 구조
- 3인 3웨이브 턴전투

## v5 우선 수정 완료
- 하늘색 단색 배경 제거, 기존 초원 지형을 다시 사용
- 그라운드에 배럴/구면형 왜곡을 적용해 고공 시점 테스트
- 지형 대비를 낮추고 청록 안개를 덧입혀 기체/탄 가독성 확보
- 구름은 배경 주체가 아니라 드문 전경/원경 깊이 단서로 축소
- 모든 기체 꼬리 추진광을 더 굵고 길게 강화
- 플레이어 대시 추진광도 강화
- 중급기 자동 출현 시간을 FIELD 1 시작 후 15초로 단축
- 키보드 8 및 화면의 '중급기 TEST' 버튼으로 즉시 테스트 가능
- G 키로 그라운드 왜곡 ON/OFF 비교 가능

## 현재 확인할 항목
- 초원 반복 타일/미러링이 실제 플레이에서 거슬리는지
- 그라운드 왜곡 강도가 과한지/약한지
- 기체와 탄의 대비가 충분한지
- 추진광이 기체 뒤쪽에서 확실히 읽히는지
- 중급기 특수공격과 침투전 진입을 15초 안에 확인 가능한지
